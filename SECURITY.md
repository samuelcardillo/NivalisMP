# Security reports

For a vulnerability involving accounts, authentication, or server access, use
[GitHub private vulnerability reporting](https://github.com/samuelcardillo/NivalisMP/security/advisories/new).
Do not post credentials, password verifiers, server identity keys, or private
account/world files in a public issue.

This is an ALPHA multiplayer mod. Account authentication is designed to
avoid transmitting the account password directly; it does not make a server you
do not trust safe. Use a unique password and verify the server's identity before
trusting it. Review the hosting instructions before exposing a server to the
internet. WAN connectivity has not been validated for this alpha.
